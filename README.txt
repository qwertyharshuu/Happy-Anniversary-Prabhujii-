DEPLOY TO VERCEL:
1. Go to https://vercel.com/new
2. Import/upload this project folder.
3. Deploy. The site is static, so no build command is needed.
4. Vercel gives you a shareable .vercel.app link.

CUSTOMIZE:
Open index.html and change the text/date if needed. The countdown is currently set to 13 September 2026 at midnight IST.

NOTE:
The music button creates a small original browser-generated melody, so no copyrighted audio file is included. If you want a specific song, add your own licensed MP3 and I can wire it into the player.
